# Fra030.github.io

Pagina statica per GitHub Pages che mostra una scritta centrale e dei girasoli SVG che "piovono" dall'alto.

Caratteristiche:
- Mobile-first, layout responsive.
- Motore visuale in HTML/CSS/JS con SVG (nessuna immagine esterna).
- Giralsoli che cadono all'infinito, ruotano e oscillano.
- Al tocco/click i girasoli esplodono in piccoli petali.
- Rispetto di `prefers-reduced-motion` per accessibilità.

Per pubblicare su GitHub Pages:
1. Sposta o sincronizza il contenuto di questa cartella nella branch `gh-pages` oppure imposta la sorgente Pages su `main` / (root) nelle impostazioni del repository.
2. Il file principale è `index.html`.

Buon deploy!
